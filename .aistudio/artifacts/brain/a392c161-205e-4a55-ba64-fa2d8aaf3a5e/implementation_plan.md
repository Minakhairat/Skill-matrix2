# Industrial Skills Matrix & Line Balancing System (نظام مصفوفة المهارات وموازنة خطوط الإنتاج)

نظام متقدم لإدارة وتقييم كفاءات 400+ عامل على مختلف خطوط الإنتاج وموديلات التصنيع، وتتبع أهداف التغطية لكل مرحلة وأهداف المرونة لكل عامل، مع أدوات تحليل الفجوات واقتراح إعادة التوزيع الفوري واستيراد/تصدير Excel/CSV.

---

## User Review & Critical Decisions

> [!IMPORTANT]
> بناءً على إجابتك بتضمين جميع الإمكانيات المقترحة، تم اعتماد المواصفات التالية في النظام:

- **إدارة البيانات الشاملة (400 عامل)**:
  - **مولد بيانات واقعي فوري (One-Click 400 Workers Seed)**: لتجربة النظام فوراً بـ 400 عامل موزعين على خطوط إنتاج وموديلات مختلفة ومراحل متنوعة.
  - **استيراد وتصدير Excel و CSV**: مع إمكانية تحميل قالب إكسيل فارغ معتمد ومملوء بنموذج، وتصدير كامل المصفوفة أو التقارير.
  - **تحرير يدوي مباشر وسريع**: تعديل درجات التقييم (1 إلى 4) بنقرة واحدة داخل خلايا الجدول مباشرة، وإضافة أو تعديل العمال والخطوط والمراحل بسهولة.

- **نظام التقييم الرباعي (4-Level Matrix Scale)**:
  - المستوى 1: متدرب / مبتدئ (Trainee)
  - المستوى 2: يعمل تحت إشراف (Under Supervision)
  - المستوى 3: مستقل / كفء ومتقن (Autonomous / Capable)
  - المستوى 4: خبير ومدرب معتمد (Expert / Trainer)
  - إمكانية تخصيص مسميات ومعايير الدرجات من لوحة إعدادات النظام.

- **محرك الأهداف الذكي (Multi-Skilling & Line Balancing Engine)**:
  - **هدف المرحلة (Workstation Target)**: تحديد عدد العمال المطلوب لكل مرحلة والحد الأدنى للدرجة المطلوبة (مثلاً 5 عمال بدرجة ≥ 3).
  - **هدف العامل (Worker Flexibility Target)**: تتبع أن يكون كل عامل مؤهلاً على عدد محدد من المراحل بدرجة مستهدفة (مثلاً 3 مراحل بدرجة ≥ 3).
  - **تحليل الفجوات (Gap Analysis & Reallocation)**: خوارزمية ذكية تكتشف مراحل العجز وتقترح ترشيح العمال المؤهلين لنقلهم أو تدريبهم لسد الفجوة فوراً.

- **تعدد الواجهات والتوافق**:
  - واجهة عربية كاملة داعمة للـ RTL مع إمكانية التبديل إلى الإنجليزية.
  - استجابة سريعة جداً لشاشات الحواسيب، الأجهزة اللوحية (Tablets للمشرفين داخل صالة الإنتاج)، والهواتف الذكية.
  - تقارير مخصصة للطباعة والتصدير جاهزة للمديرين واجتماعات الورديات.

## 1. Overview & Core Concept

- **طبيعة النظام**: منصة تشغيلية للمصانع وخطوط التجميع تتيح لمديري الإنتاج ومسؤولي الجودة والتدريب إدارة مصفوفة المهارات (Skills Matrix / ILU Matrix) ومراقبة خطوط الإنتاج المتعددة (Production Lines)، وربطها بالموديلات المصنّعة (Product Models)، ومراحل التشغيل (Operations / Workstations).
- **الجمهور المستهدف**: مديرو المصانع، رؤساء خطوط الإنتاج (Line Supervisors)، مهندسو الكفاءة والـ Lean Manufacturing، ومسؤولو الموارد البشرية والتدريب.
- **القيمة الأساسية**: القضاء على توقف خطوط الإنتاج بسبب غياب أو نقص كفاءة العمال، وتطبيق معايير التصنيع الرشيق (Multi-skilled Workforce) لضمان مرونة 3 مراحل لكل عامل وتغطية كافية لكل مرحلة حرجة.

## 2. User Experience & Visual Design

### Key User Flows

1. **المصفوفة التفاعلية الرئيسية (Main Matrix Grid)**:
   - شريط تصفية فائق السرعة: اختيار خط الإنتاج (مثلاً: خط 1، خط 2، خط 3...)، واختيار الموديل الحالي.
   - جدول ذكي فائق السرعة يدعم تثبيت الأعمدة (Freeze Employee Name/ID) وتثبيت رأس الجدول (Sticky Stages Header).
   - خلايا التقييم تفاعلية: النقر السريع يغير الدرجة (0, 1, 2, 3, 4) فورياً مع مؤشر لوني معتمد عالمياً في إدارة المصانع (مثل درجات الأخضر والأزرق والبرتقالي).
   - صف إحصائي سفلي فوري يوضح إجمالي العمال المؤهلين لكل مرحلة ونسبة تحقيق الهدف اللحظي.

2. **لوحة موازنة الخط وتحليل الفجوات (Line Balancing & Gap Dashboard)**:
   - كروت حالة سريعة: نسبة تغطية مراحل الخط، مؤشر مرونة العمال (نسبة العمال متعددي المهارات ≥ 3 مراحل)، وعدد المراحل التي بها عجز حرج.
   - شاشة الفجوات التفاعلية: جدول يعرض كل مرحلة: (المطلوب vs المتوفر حالياً vs الفجوة).
   - زر "اقتراح الحلول الذكية (Smart Rebalancing)": يقترح تلقائياً عمال من خطوط أو مراحل أخرى لديهم مؤهلات لسد العجز.

3. **شاشة ملفات العمال وتتبع التدريب (Workers & Multi-Skill Tracker)**:
   - عرض قائمة الـ 400 عامل مع مؤشر مرونة لكل عامل (مثال: متقن لـ 3 من 3 مراحل مستهدفة 100%).
   - إمكانية البحث بالاسم أو الكود الوظيفي وتحديد مسار تدريبي للعامل لترقيته إلى المستوى التالي في مرحلة معينة.

4. **مركز استيراد وتصدير البيانات (Data & Reports Hub)**:
   - تصدير كامل إلى Excel (.xlsx / .csv) وتصدير مخصص للطباعة الرسمية (PDF Print View).
   - استيراد ملف خارجي مع فحص مسبق لصحة البيانات (Validation).
   - زر إعادة تعيين أو توليد 400 عامل تجريبي لاختبار كافة السيناريوهات.

### Visual Identity & Theme

- **النمط البصري**: واجهة صناعية احترافية (Clean Industrial Precision) مبنية بأعلى معايير التصميم الخالي من الزخارف الزائفة.
- **لوحة الألوان**:
  - خلفية عامة محايدة عالية الوضوح: Slate-50 / Crisp White.
  - الهيكل والأسطح: Slate-900 / Slate-800 للنصوص والعناوين الرئيسية مع حدود رمادية ناعمة (Slate-200/300).
  - درجات المهارة البصرية المعتمدة:
    - المستوى 0 (غير مدرب): رمادي فاتح مفرغ.
    - المستوى 1 (متدرب): أصفر دافئ / Amber-500.
    - المستوى 2 (تحت إشراف): أزرق سماوي / Sky-500.
    - المستوى 3 (مستقل - الهدف القياسي): أخضر زمردي / Emerald-600.
    - المستوى 4 (مدرب وخبير): نيلي / Indigo-600 مع شارة تميز.
- **الطباعة**: خطوط عربية ولاتينية هندسية واضحة (`Plus Jakarta Sans` / `Cairo` / `Tajawal` مع خطوط الأرقام الجداولية `tabular-nums` لثبات الأرقام والمقاييس).

## 3. Key Product Decisions & Trade-Offs

- **الأداء السلس لـ 400 عامل**:
  - التعامل مع شبكة مكونة من 400 عامل × 15-25 مرحلة = حتى 10,000 خلية تفاعلية.
  - *الحل المعتمد*: تقسيم عرض المصفوفة بذكاء مع فلترة الخطوط/الموديلات ودعم التصفح السريع والصفحات الافتراضية مع تقليل عمليات إعادة التصيير (Re-renders) عبر React useMemo و useCallback لضمان سرعة استجابة فورية (< 16ms).
- **تخزين البيانات والمرونة**:
  - تخزين محلي تلقائي في المتصفح (IndexedDB / LocalStorage) لحفظ كافة التعديلات في الوقت الفعلي مع عدم فقدان أي بيانات عند تحديث الصفحة.
  - إمكانية التصدير والاستيراد لتبادل البيانات كملفات Excel/JSON بين مسؤولي الورديات.
- **تخصيص الأهداف**:
  - إتاحة تعديل الأهداف ديناميكياً لكل مرحلة ولكل خط، ولكل عامل، دون الحاجة لإعادة ضبط النظام بالكامل.

### Data Schema Entities

1. **Worker**:
   - `id`: string (e.g. `EMP-001` .. `EMP-400`)
   - `name`: string
   - `productionLineId`: string (e.g. `LINE-A`, `LINE-B`, `LINE-C`, `LINE-D`)
   - `targetStagesCount`: number (افتراضياً 3)
   - `minProficiencyTarget`: number (افتراضياً 3)
   - `skills`: Record<stageId, number> (درجات من 0 إلى 4)

2. **ProductionLine**:
   - `id`: string
   - `name`: string
   - `models`: Model[]

3. **Model**:
   - `id`: string
   - `name`: string
   - `stages`: Stage[]

4. **Stage (Workstation / Operation)**:
   - `id`: string
   - `name`: string
   - `targetWorkersCount`: number (افتراضياً 5)
   - `minRequiredLevel`: number (افتراضياً 3)
   - `criticality`: 'high' | 'medium' | 'normal'

5. **Balancing & Gap Metrics**:
   - `currentQualifiedCount`: number (عدد العمال ذوي الدرجة ≥ المستوى المطلوب)
   - `gap`: number (`targetWorkersCount` - `currentQualifiedCount`)
   - `status`: 'covered' | 'shortage' | 'critical'

## 5. Verification & Implementation Steps

1. **Step 1: بناء هيكل البيانات والمولد الذكي (Data Layer & Mock Generator)**
   - إنشاء بيانات نموذجية متكاملة لـ 400 عامل موزعين على 4 خطوط إنتاج و 8 موديلات ومراحل متنوعة ليعمل التطبيق فور تشغيله.
   - دوال حساب مؤشرات التغطية والفجوات والمرونة في الوقت الحقيقي.

2. **Step 2: بناء واجهة المصفوفة التفاعلية عالية الأداء (Skills Matrix View)**
   - جدول ذكي يدعم تثبيت رأس الجدول والأعمدة الجانبية.
   - خلايا تفاعلية قابلة للنقر السريع للتنقل بين التقييمات (0 -> 1 -> 2 -> 3 -> 4).
   - بحث وفلاتر متعددة سريعة حسب الخط، الموديل، مرحلة العمل، ومستوى التقييم.

3. **Step 3: بناء لوحة تحليل الفجوات وموازنة الخط (Gap Analysis & Smart Balancing)**
   - مؤشرات بصرية لمدى جاهزية كل مرحلة.
   - خوارزمية ذكية لاقتراح عمال لسد العجز في المراحل الحرجة.
   - محاكي تعديل أهداف المراحل (تغيير الـ 5 عمال أو الدرجة المطلوبة فوراً ومشاهدة النتائج).

4. **Step 4: بناء شاشة العمال ومؤشر مرونة العامل (Worker Multi-Skilling)**
   - بطاقات وجدول العمال لمتابعة هدف الـ 3 مراحل لكل عامل.
   - إمكانية إضافة وتعديل العامل بسهولة.

5. **Step 5: أدوات الاستيراد والتصدير والطباعة (Excel / CSV & Print Engine)**
   - تصدير كامل إلى Excel/CSV واستيراد الملفات.
   - واجهة مخصصة للطباعة الرسمية (Print Ready View) لمشاركتها مع إدارة المصنع.
   - فحص سلامة البناء وتوافق المتصفحات عبر `compile_applet`.
